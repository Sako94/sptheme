# SoftPauses Quick PDP — copy in Zorix structure

A more transactional, above-the-fold-conversion-optimized PDP variant.
Same brand voice, same sections (mostly), tighter pacing. Built as an
alternate product template at `templates/product.softpauses-quick.json`
so you can A/B test it against the editorial long-form PDP.

How to assign in Shopify admin:
1. Products -> SoftPauses product -> right sidebar -> Theme template
2. Choose **softpauses-quick** instead of **softpauses**
3. Save. Customize copy/images via Theme Editor.

## What's different from the editorial long-form PDP

| Editorial (current) | Quick (this variant) |
|---|---|
| 24 sections | ~14 sections |
| Long pain agitation (6 cards) | None — straight to product |
| Mechanism + patch anatomy + timing arc + how-it-works + absorption compare | Single "how it works" video + short descriptive callout |
| 4 ingredient cards with deep copy | Listed inside accordion only |
| Sourcing map | Removed |
| Cost calculator | Removed |
| Detailed buy box mid-page | Compact buy in hero (above the fold) |
| Advisors section | Replaced by stat-with-image cards |
| Detailed clinical chart + rings | Single stats card under "Why Decide" |

**Use the editorial version** for organic / SEO / content-marketing traffic where dwell time is high.

**Use the Quick version** for paid traffic / Meta / TikTok / Pinterest where shoppers click in with intent and need to convert in 30 seconds.

---

## Implementation

The alternate template file is at `templates/product.softpauses-quick.json`.
It uses the existing sp-* sections with reworked copy + a shorter section order.

To apply: Shopify admin -> Products -> SoftPauses -> Theme template -> select **softpauses-quick** -> Save.

You can also create a new product (e.g. "SoftPauses Patch — Quick Buy") with the same product handle pointed at a different template if you want to run both PDPs simultaneously for A/B tests.
